## 🧠 AI / ML lab

<table>

<td width="50%" valign="top">

### [Agentic Dissonance](https://github.com/Nikshay1/market-volatility-using-multiple-LLMS)

**Can disagreement between heterogeneous LLM agents predict future market volatility?**

A research-oriented Python pipeline with specialized agents, blind + critique rounds, confidence-weighted disagreement signals, forward volatility models, out-of-sample evaluation, regime analysis, and forecast-comparison testing.

`Python` `LLM Agents` `Groq` `Ollama` `scikit-learn` `statsmodels` `time-series`

<td width="50%" valign="top">

### [AI-Enhanced Hiring Decisions](https://github.com/Nikshay1/AI-Enhanced-Hiring-Decisions)

**Hybrid semantic retrieval for matching natural-language queries against candidate/work descriptions.**

Combines Sentence Transformers embeddings, cosine similarity and BM25 ranking behind a Python/Flask API — a practical retrieval system rather than a keyword-only search demo.

`Python` `Sentence Transformers` `BM25` `Embeddings` `NumPy` `Flask`

</td>
</tr>

<td width="50%" valign="top">

### [SS-DBSCAN](https://github.com/Nikshay1/SS-DBSCAN---Semi-Supervised-DBSCAN)

**Semi-supervised density clustering implemented and evaluated from scratch.**

Reproduces a research-paper variant of DBSCAN, adds a domain-aware core-point condition, and compares clustering quality, runtime, noise behavior, and cluster structure on the UCI Letters dataset.

`Python` `Clustering` `NumPy` `SciPy` `ML Research`

</td>
<td width="50%" valign="top">

### [RecoverFlow](https://github.com/Nikshay1/AI-Payment-Failure-Recovery-Agent)

**An AI-assisted payment-recovery agent with deterministic safety gates.**

Uses an LLM for constrained recovery proposals while keeping policy, duplicate-event handling, reconciliation, auditability, and customer-contact rules outside model control.

`Agentic AI` `Groq` `Structured Outputs` `Guardrails` `Cloudflare`

## 🔬 What I like working on

```text
raw data
   │
   ├──► embeddings / retrieval ─────► ranking + search
   │
   ├──► heterogeneous LLM agents ──► disagreement + debate
   │
   ├──► statistical / ML models ───► forecasts + evaluation
   │
   └──► deterministic guardrails ──► safer AI actions

                              ↓
                     measurable systems
```

The recurring theme is simple: **don't just make the model answer — make the system prove something.**
